# Flowtica AI Website with Uploaded Hero Video

This version adds your uploaded automation video to the front hero section where task automation is shown.

## Files
- index.html
- style.css
- script.js
- assets/automation-hero.mp4

## Changes
- Added the uploaded MP4 to the hero/front-page task automation visual.
- Added a premium video overlay, live badge, grid overlay, and metric cards.
- Reused the same MP4 in the “See AI Automation in Motion” demo section.

## To replace the video
Replace `assets/automation-hero.mp4` with another MP4 using the same file name.
